# 本次调整

代码按用途迁移至 backend、scripts、configs、tests；静态页面保留在 static。根目录保留兼容启动入口，部署打包同步调整。标注数据库、缓存、检查点、虚拟环境均保留原路径。

## 修复

- 请求有超时，筛查单 EP 详情失败不再挡住全局进度刷新；失败后会自动重试。
- 保存期间的新编辑不会被旧响应覆盖，切换 EP 后旧响应也不会写入当前 EP；重复保存请求合并，导出前检查是否仍有未保存修改。
- camera / photon 读齐后整组更新；读图有超时。未同步或播放中不能直接设置接触／离开帧。
- 修复快速停止、重启播放形成多个动画循环，以及旧 EP 曲线复筛响应污染当前候选的问题。
- 复核队列无变化时不重新创建按钮，减少轮询打断操作。
- 挂载诊断脚本改用兼容新旧 Determined 的认证入口。

## 性能定位

新筛查记录增加 `current.stage`、`last_window.read_seconds`、`last_window.model_seconds`、`last_window.total_seconds`，网页显示上窗分项耗时。模型调用时间包括该调用中的加载、等待和预处理，不等于纯 GPU 生成时间。旧历史记录没有这些分项，仍可正常读取。

尚未更换模型或承诺推理提速。需要重新部署后，在同一个 EP 上根据分项耗时判断瓶颈。

## 检查

后端和部署打包共 48 项测试（1 项真实数据测试跳过）、7 项客户端测试，以及 3 组 Node 前端回归检查通过。部署测试实际构建上传目录并导入其中的服务，但不连接集群、不创建实验。未进行真实浏览器布局或 GPU 新版验收。
